About the platform

Gencore Module Packaging System

A comprehensive bioinformatics software resource designed for researchers using the NYU Abu Dhabi High-Performance Computing cluster.

This website provides detailed information about genomics software modules available on Jubail, together with step-by-step instructions for loading them efficiently. Explore the software versions currently supported for each module and select the version that is compatible with your project.

You can also request the installation of new software to meet specific research requirements. Private meta-modules can combine two or more existing modules into a single, unified environment for more streamlined and reproducible workflows.
